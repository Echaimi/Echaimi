## À propos

Je suis **Elyas Chaimi**, développeur full stack basé à **Paris**, avec **plus de 5 ans d’expérience** dans l’e-commerce, la fintech et le SaaS.

Je développe des produits de **l’interface à l’infrastructure** : applications React, design systems, API REST, microservices Node.js et pipelines de déploiement. Mon expérience couvre la modernisation d’un monolithe PHP legacy, la refonte de parcours clients et le développement de tableaux de bord d’investissement.

Aujourd’hui, je me concentre sur **l’IA appliquée et la génération augmentée par récupération (RAG)**. Avec **RepoSage**, **ShopMind** et **Confluo**, je travaille sur le découpage de code par AST, la recherche hybride, le reclassement des résultats et les réponses accompagnées de citations explicites.

Mon approche de l’ingénierie produit : comprendre le parcours utilisateur, définir des contrats clairs et mener l’implémentation sur le front-end, le back-end et l’infrastructure.

**Formation :** Master en ingénierie du web · ESGI<br />
**Langues :** français · arabe · anglais — TOEIC 920 · espagnol

## Projets à la une

<details open>
<summary><strong>RepoSage — Compréhension de dépôts</strong></summary>

<br />

Un assistant pour les dépôts GitHub qui répond aux questions sur le code avec **citations du fichier et des lignes**.

| Dimension | Détails |
| :--- | :--- |
| **Stack** | TypeScript · Next.js · Tree-sitter · LangChain.js · LlamaIndex.js · Weaviate · Vercel AI SDK |
| **Périmètre** | Dépôts JavaScript / TypeScript ; analyse extensible à Python et Go |
| **Performance** | Découpage par AST, recherche vectorielle + BM25 et réponses en streaming |
| **Sécurité** | Contrôles d’accès non précisés dans la présentation publique du projet |
| **Impact** | Relie les réponses aux fonctions, classes, modules et emplacements dans les sources |
| **Dépôt** | [github.com/Echaimi/RepoSage](https://github.com/Echaimi/RepoSage) |

RepoSage conserve la structure du code lors de la recherche. Tree-sitter identifie les frontières syntaxiques pertinentes, la recherche hybride combine le sens et les termes exacts, et les citations permettent de retrouver chaque réponse dans le dépôt.

</details>

<br />

<details>
<summary><strong>ShopMind — Assistant e-commerce avec sources</strong></summary>

<br />

Un chatbot e-commerce combinant **fiches produit, avis clients et stocks en temps réel**.

| Dimension | Détails |
| :--- | :--- |
| **Stack** | Next.js · Vercel AI SDK · Pinecone · PostgreSQL |
| **Périmètre** | Fiches produit, avis clients et données de disponibilité |
| **Performance** | Filtrage par métadonnées : prix, catégorie et disponibilité |
| **Sécurité** | Contrôles d’accès non précisés dans la présentation publique du projet |
| **Impact** | Synthèse des avis avec sources citées et repli lorsque l’information manque |
| **Dépôt** | [github.com/Echaimi/ShopMind](https://github.com/Echaimi/ShopMind) |

ShopMind appuie ses réponses sur le catalogue et les stocks. Les filtres de métadonnées ciblent les sources pertinentes, les synthèses d’avis conservent leurs références, et l’assistant propose une réponse de repli lorsque les données ne permettent pas de répondre.

</details>

<br />

<details>
<summary><strong>Confluo — Recherche documentaire multi-source</strong></summary>

<br />

Un moteur de recherche pour **Notion, Slack, Markdown et les documents PDF**.

| Dimension | Détails |
| :--- | :--- |
| **Stack** | TypeScript · LangChain.js · LlamaIndex.js · Qdrant · Cohere Rerank · PostgreSQL |
| **Périmètre** | Quatre types de sources, chacun avec un pipeline d’ingestion dédié |
| **Performance** | Recherche dense + sparse, reclassement, déduplication et streaming |
| **Sécurité** | Contrôles d’accès non précisés dans la présentation publique du projet |
| **Impact** | Citations au niveau des passages dans des sources documentaires hétérogènes |
| **Dépôt** | [github.com/Echaimi/Confluo](https://github.com/Echaimi/Confluo) |

Confluo réunit des connaissances dispersées dans un même pipeline de recherche. L’ingestion par source, la recherche hybride et le reclassement Cohere identifient les passages pertinents ; la déduplication entre sources réduit les répétitions et les citations préservent la traçabilité.

</details>
